AI Tools Guide

생성형 AI 서비스 소개

Prompt 작성부터 이미지·음악·영상·문서 생성까지 — 주요 생성형 AI 서비스와 활용 예시를 한눈에 확인하세요.

주요 서비스 상세

🤖
ChatGPT
chatgpt.com
텍스트 생성·분석·요약·번역 등 범용 언어 AI. 심층 리서치(Deep Research) 기능으로 출처 기반 보고서 자동 작성 가능.
예시 Prompt

한국의 반도체 산업에 대한 투자 전망 보고서를 개조식으로 생성해주세요. 출처를 정확히 표시하고 환각이 없는지 점검해서 작성해 주세요.

심층 리서치 보고서 생성 이미지 생성
🧠
Claude
claude.ai
Anthropic의 AI 어시스턴트. 긴 문서 분석·코드 작성에 강점. 생성 결과를 DOCX·PPTX 파일로 직접 다운로드 가능.
예시 Prompt

한국의 반도체 산업 투자 전망 보고서를 개조식으로 작성해 주세요. 생성된 결과는 [docx|pptx] 파일로 다운로드할 수 있게 해주세요.

문서 생성 DOCX·PPTX 코드 작성
✨
Gemini (Canvas)
gemini.google.com
Google의 멀티모달 AI. Canvas 기능으로 생성된 문서·이미지를 시각적으로 편집하고, 부분 수정 요청이 가능.
활용 포인트

이미지 생성 후 "배경을 더 밝게", "텍스트 위치 변경" 등 자연어로 부분 수정 요청 가능

Canvas 편집 이미지 생성 노래 만들기
🎵
Suno
suno.com
텍스트 설명만으로 완성된 노래를 생성하는 AI 음악 서비스. 장르·분위기·가사 스타일 지정 가능.
예시 Prompt

20대 학생의 사랑과 이별을 노래한 발라드 곡. 첫 만남에 사랑에 빠졌으나 사소한 다툼으로 헤어진 후 다시 만나고 싶은 마음을 담은 노래

음악 생성 가사 포함 장르 설정
📚
NotebookLM
notebooklm.google.com
업로드한 자료(PDF, 문서 등)를 기반으로 질의응답·요약·팟캐스트 생성. 자료 업로드 필수.
활용 방법

PDF·Google Docs·웹페이지 등을 소스로 업로드 후, 해당 자료 기반으로만 답변하는 RAG 챗봇으로 활용

RAG 챗봇 자료 분석 팟캐스트
🎬
Google Flow
labs.google/fx/tools/flow
시작 프레임을 제시하면 AI가 영상을 생성하는 비디오 생성 도구. 초 단위로 장면 변화를 세밀하게 지정할 수 있음.
활용 팁

시작 프레임의 변화 과정을 제시하고, 초 단위로 구분해서 제시하면 더욱 정밀한 영상 생성 가능

영상 생성 프레임 제어 Labs 실험
